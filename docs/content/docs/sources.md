## Source handling

Prefer first-party documentation, versioned model cards, pricing pages, release
notes, repositories, and benchmark publications. Label each observation as
measured, vendor-reported, derived, estimated, or unknown. See the [Research
Data Policy]({{< relref "/docs/research-data-policy" >}}) for retention,
attribution, and verification rules.
