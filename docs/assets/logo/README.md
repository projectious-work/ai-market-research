# signal room — logo assets

Product-line extension of projectious.work. Mark drawn on the 40-unit brand grid; the outer petal keeps the brand mark's asymmetric inner knockout, is broken open on the right flank, and the signal wave crosses the break.

## Colours
- ring / structure: midnight-9 `#1d3352` (light), `#cfd9e4` (dark)
- wave: orange-9 `#e05232` — on dark it carries a fine white contour
- wordmark: `#142438` + accent `#c04424` (light) · `#e8edf4` + `#ea7558` (dark)

## Files
| File | Use |
|---|---|
| `svg/icon-light.svg` | mark on light surfaces |
| `svg/icon-dark.svg` | mark on navy / deep dark |
| `svg/icon-small-light.svg` | simplified cut for 16–20 px |
| `svg/icon-mono-black.svg` | one-colour, dark ink |
| `svg/icon-mono-white.svg` | one-colour, reversed |
| `svg/lockup-horizontal-light.svg` | mark + wordmark, light |
| `svg/lockup-horizontal-dark.svg` | mark + wordmark, navy |
| `png/*` | rasterised marks and favicons |

## Rules
- Minimum size: 16 px for the mark (use the simplified cut below 20 px), 24 px for any lockup with the wordmark.
- Clear space: half the mark's height on all sides.
- Never recolour the wave. Never fill the break.
- Lockup type is Plus Jakarta Sans 600, letter-spacing -0.5 px. The SVG lockups use live text — convert to outlines before sending outside systems that have the font.
